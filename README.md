# 🌤️ WeatherApp

A simple weather application built with **HTML, CSS, and JavaScript** that fetches live weather data from the [OpenWeatherMap API](https://openweathermap.org/api).  
Users can search for any city and see the current temperature, weather condition, humidity, wind speed, and "feels like" temperature.  

---

## 📸 Features
- Search weather by **city name**
- Displays:
  - 🌡️ Temperature
  - 🌬️ Wind speed
  - 💧 Humidity
  - 🌡️ Feels like temperature
- Shows **weather icons** (clear, clouds, rain, snow, etc.)
- Dynamic **date & time** display
- Responsive design (works on desktop & mobile)

---

## 🛠️ Tech Stack
- **HTML5**
- **CSS3**
- **JavaScript (Vanilla JS)**
- **OpenWeatherMap API**
